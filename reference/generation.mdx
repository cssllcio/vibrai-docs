Generate or plan a composition from a .vibrai project file.

## Command line

### `generate`

Generate clips and arrangement from a .vibrai project file

```bash
vibrai generate --project <PATH> --force --clear-first --dry-run --seed <VALUE> --allow-skip --with-instruments --stock-only --on-existing-tracks <MODE> --keep-empty-clips --session-only --swing <PCT> --humanize <PCT> --ornaments <PCT> --dropout <PCT> --gate <PCT> --bass-motion <PROFILE> --kick-relation <MODE> --native-randomization --number-tracks --no-number-tracks
```

<ParamField path="--project">
  Path to .vibrai file (default: Untitled.vibrai in CWD)
</ParamField>
<ParamField path="--force">
  Overwrite existing session clips and arrangement content in project tracks
</ParamField>
<ParamField path="--clear-first">
  Delete all Vibrai-generated tracks (same rule/order as 'vibrai project clear --yes') before planning and rendering — a clean slate so this run's composition doesn't stack on top of a previous, different project's tracks. Never touches Audio/Return/Master tracks or MIDI tracks whose Part Type is Other (user/template tracks). Skipped entirely under --dry-run (which never calls the bridge).
</ParamField>
<ParamField path="--dry-run">
  Plan only — do not call the bridge
</ParamField>
<ParamField path="--seed">
  Override the project's T2mHash seed for this run
</ParamField>
<ParamField path="--allow-skip">
  Continue when arrangement-automation entries cannot be resolved; default fails fast.
</ParamField>
<ParamField path="--with-instruments">
  After rendering, load each part's default instrument (drum kits for drum parts) so the song is audible.
</ParamField>
<ParamField path="--stock-only">
  Resolve instruments from stock content only: skips explicit defaults.instruments overrides AND tagged instruments, using genre stock defaults + built-in generic. For demos/testing without third-party packs.
</ParamField>
<ParamField path="--on-existing-tracks">
  How to treat existing MIDI tracks: replace (delete them) or append (keep, add after last MIDI track). Default: append. Audio/return tracks are always left in place.
</ParamField>
<ParamField path="--keep-empty-clips">
  Keep generator-produced clips that resolve to zero notes. By default these are skipped, leaving a gap in both session and arrangement views. Authored literal empty clips are always kept.
</ParamField>
<ParamField path="--session-only">
  Write clips to the Session grid only; skip Arrangement placement. Use with play-song to drive the song from Session view.
</ParamField>
<ParamField path="--swing">
  Swing amount 0-100 (0 straight, 100 hard triplet). Overrides genre/preset default.
</ParamField>
<ParamField path="--humanize">
  Velocity/timing jitter 0-100. Overrides genre/preset default.
</ParamField>
<ParamField path="--ornaments">
  Grace-note/roll density 0-100. Overrides genre/preset default.
</ParamField>
<ParamField path="--dropout">
  Tension-section note thinning 0-100. Overrides genre/preset default.
</ParamField>
<ParamField path="--gate">
  Note articulation length 0-100 (10 = extreme staccato, 100 = full value/legato). Overrides genre/preset default.
</ParamField>
<ParamField path="--bass-motion">
  Bass motion profile: root, root_fifth, octave_pump, arpeggiated, walking, pedal. Overrides genre default.
</ParamField>
<ParamField path="--kick-relation">
  How the bass sits against the kick: lock (snap onto it), dodge (push off it), free (ignore it). Overrides genre default.
</ParamField>
<ParamField path="--native-randomization">
  Emit Live's per-note probability/velocity-deviation instead of baking randomization in. The loop then varies on every playback, but the audible result is no longer reproducible from the seed. Omit to inherit the genre's setting.
</ParamField>
<ParamField path="--number-tracks">
  Prefix track names with Ableton's '#' auto-numbering token for this run.
</ParamField>
<ParamField path="--no-number-tracks">
  Disable '#' track auto-numbering for this run (overrides env / project setting).
</ParamField>

### `generate`

Plan + render a composition into Live's session view and arrangement view. force=true is required only when append re-renders onto an existing part track whose target slots are non-empty; replace implies consent and never requires force. By default, fails fast when any ArrangementAutomationEntry cannot be resolved against the live device tree; pass allow_skip=true to log warnings and continue. Track ids in the summary (session_clips, arrangement_placements, instruments, current_tracks) are 1-based, matching list_tracks and load_device. Call `get_skill` first to load the Vibrai operational playbook.

```json
{
  "tool": "generate",
  "arguments": {
    "project_path": "<String>",
    "force": "<Boolean>",
    "allow_skip": "<Boolean>",
    "with_instruments": "<Boolean>",
    "stock_only": "<Boolean>",
    "on_existing_tracks": "<String>",
    "seed": "<Nullable`1>",
    "keep_empty_clips": "<Boolean>",
    "swing": "<Nullable`1>",
```
